# Security Policy

This is a pre-release experimental scanner. Do not point it at private services, credentials-bearing URLs or internal networks. It currently follows cross-origin redirects and is not hardened for scanning untrusted targets inside cloud infrastructure.

Please **do not disclose vulnerabilities in public issues**. Use GitHub's private vulnerability reporting if it has been enabled for the repository, or contact the maintainer privately through their GitHub profile.

There are no supported stable releases yet.
